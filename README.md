# ハロプロ ジャケ写パズル

ハロー！プロジェクトのジャケット写真で遊べる、非公式のジグソーパズルゲームです。

- グループ → ジャンル（シングル・アルバム・映像・写真集など）からジャケ写を選ぶ
- ピース数（12〜300）と難易度（かんたん／ふつう／むずかしい）を選んでスタート
- ジャケ写一覧は [helloproject.com](https://helloproject.com/) から毎日自動で取り直すので、新譜にも自動で対応

## 遊び方

| 操作 | PC | スマホ |
| --- | --- | --- |
| ピースを動かす | ドラッグ | ドラッグ |
| 複数のピースをまとめて動かす | 空いている所をドラッグで範囲選択 → 赤く光ったピースをドラッグ | 空いている所をなぞって範囲選択 → 赤く光ったピースをドラッグ |
| 選択を解除 | 空いている所をクリック／`Esc` | 空いている所をタップ |
| ピースを回す（むずかしい） | クリック／右クリック | タップ |
| ズーム | ホイール／`+` `-` | 2本指でピンチ |
| 画面を動かす | 右ドラッグ／中ボタンドラッグ | 2本指でドラッグ |
| 見本を表示 | `P` | 🖼 ボタン |
| 端のピースだけ表示 | `E` | ⬚ ボタン |
| 全体を表示 | `F` | ⛶ ボタン |
| 一時停止 | `Space` | ⏸ ボタン |

- 正しい隣同士のピースを近づけると、自動でくっつきます。ボードの正しい位置に置くと固定されます。
- 遊んでいる途中の状態は自動で保存されます（ブラウザごと・最大 12 パズル分）。同じジャケ写・ピース数・難易度を選ぶと「続きから」が出ます。
- 自己ベストタイムは、ジャケ写・ピース数・難易度の組み合わせごとに記録されます。

| 難易度 | 内容 |
| --- | --- |
| かんたん | ボードに見本がうっすら表示される |
| ふつう | 見本なし |
| むずかしい | 見本なし＋ピースがランダムに回転している |

## 開発

依存パッケージはありません。Node.js 20 以上があれば動きます。

```sh
npm run fetch-data   # helloproject.com から最新のリリース一覧を取得 → public/data/releases.json
npm run dev          # http://localhost:5173/ で起動
```

### ファイル構成

```
public/                 そのまま公開される静的サイト（ビルド不要）
  index.html
  css/style.css
  data/releases.json    リリース一覧（fetch-data で生成）
  js/
    main.js             画面の切り替え（#/ = ホーム、#/play/... = ゲーム）
    home.js             ホーム画面とピース数・難易度の設定パネル
    game.js             ゲーム画面のツールバーとリザルト画面
    data.js             データ読み込み、ピース数・難易度の定義
    storage.js          自己ベスト・途中保存（localStorage）
    sound.js            効果音（WebAudio で合成）
    puzzle/
      engine.js         パズル本体（描画・ドラッグ・回転・吸着・ズーム）
      geometry.js       ピースの凸凹の形
scripts/
  fetch-releases.mjs    リリース一覧の取得スクリプト
  serve.mjs             開発用サーバー
```

### データ取得のしくみ

helloproject.com の各グループの「リリース」ページは、年ごとの JSON（`/json/{バージョン}/{年}_releases.json`）を読み込んで一覧を表示しています。`fetch-releases.mjs` は次の手順でデータを集めます。

1. トップページからグループ一覧を取得
2. 各グループのリリースページから、グループ ID と JSON の置き場所を取得
3. 年別の JSON と、まだ年別 JSON に載っていない新譜を集めて 1 つのファイルにまとめる

ブラウザから helloproject.com のデータを直接読むことはできない（CORS 制限）ため、事前に JSON にまとめる方式にしています。ジャケ写の画像自体はダウンロードせず、helloproject.com から直接表示しています。

## 公開（GitHub Pages）

`.github/workflows/update-and-deploy.yml` は、毎朝 6:00 (JST) にリリース一覧を取り直し、変更があればコミットして GitHub Pages に公開します。main ブランチへの push でも公開されます。

初回だけ、リポジトリの **Settings → Pages → Build and deployment → Source** を **GitHub Actions** に変更してください。

> GitHub の仕様で、リポジトリに 60 日間動きがないと定期実行が止まることがあります。止まったら Actions タブから再度有効にしてください。
